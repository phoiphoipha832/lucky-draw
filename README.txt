BCEL ONE LUCKY DRAW - iPad Edition
=====================================

เปิด index.html เพื่อเริ่มใช้งาน

วิธีใช้งาน:
1. เปิด index.html บน iPad ด้วย browser
2. กด START เพื่อเล่น Lucky Draw
3. กด "Admin / Setup Prize" เพื่อเพิ่ม/แก้ไขรางวัล

ระบบรางวัลใหญ่:
- Big prize every N plays = จำนวนครั้งที่ต้องการให้รางวัลใหญ่บังคับออก
- เช่น 10 = ครั้งที่ 10, 20, 30... จะออก Big Prize
- ตั้งเป็น 0 เพื่อปิดระบบรางวัลใหญ่

ข้อมูลจะถูกเก็บใน Browser ของเครื่องนั้นด้วย localStorage
